## How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/pyspark-learning-notes.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Open the notebook:

```bash
jupyter notebook
```
